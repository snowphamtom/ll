# Say

A notebook web source stores the page text it scraped when the URL was added.

That is the whole download. It is not a live pipe. A sentence written after the scrape is not in the notebook until the source is replaced or a new path is added.

## What this shelf will put in a URL

Public plates only. This repo is public. A raw URL is readable without a GitHub login.

In: hinge rules, caps, a named public file, a note that was pasted back into `return/` and committed.

Out: private trees, mail, unreleased filings, and anything that was not already on this repo.

## Refresh

1. Delete the old source in the notebook.
2. Add the same raw URL again, or add a new path.
3. The notebook keeps the new scrape. It does not follow later commits by itself.

Drive files are the living hinge. These raw URLs are not.
