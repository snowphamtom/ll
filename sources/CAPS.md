# Caps the hinge has to respect

These are the published source rules, not a reading of the closed notebook.

- A web URL imports the text of that page only. Images, embedded video, and nested pages stay out. Paywalled pages fail.
- Each source is capped at 500,000 words, or 200 MB for an uploaded file.
- Free accounts: 50 sources per notebook. A deselected source still occupies a slot.
- YouTube imports captions only, and only for a public video. GitHub is not YouTube.
- A PDF URL is treated as a PDF source. A markdown raw URL is treated as a web page.
- Footnotes and comments on Google files are not imported. This repo has neither.

If a plate grows past the word cap, split it. Do not rely on the notebook to truncate honestly.
