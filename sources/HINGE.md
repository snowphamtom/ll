## How the link actually works

A notebook answers from sources that were added and selected. GitHub is not one of those source types. A public raw file is. The hinge is that substitution.

1. A plate is committed on `main` of a public repo.
2. The raw URL is pasted into the notebook as a web source.
3. The notebook stores the text it scraped. Later commits do not move that copy.
4. To refresh, delete the source and add the same URL again, or commit a new path and add that URL.

Drive is the other hinge, and it is the living one. A Google Doc, Sheet, or Slides file imported from Drive follows the original. A GitHub raw URL does not.
